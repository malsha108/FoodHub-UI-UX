# 🍔 FoodHub – Food Delivery App UI/UX

## 🎯 Overview
A modern food delivery mobile app home screen designed for local restaurants in Daladagama & Kulyapitiya.

## 🎨 Design Process
- Created category filters (Burgers, Pizza, Rice, Drinks)
- Designed restaurant cards with ratings, delivery time, distance, and promo tags
- Used Figma for UI design and Clay Mockup plugin for 3D iPhone presentation
